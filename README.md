# Abidzar Al Ghifari — Portfolio

Personal portfolio website: hero with photo, loading animation, skills marquee,
experience, projects, and a contact section.

## Stack

- React 19 + TypeScript
- TanStack Start (SSR + server functions)
- Tailwind CSS v4
- Vite

## Run locally

```sh
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```sh
npm run build
npm run preview
```
